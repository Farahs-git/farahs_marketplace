name: partner-plugin-review description: Use this when reviewing a partner's plugin submission for the Coworker marketplace, or when asked to check if a plugin meets marketplace standards. --- # Partner Plugin Review When asked to review a partner's plugin submission, walk through this checklist and report findings clearly, grouped as Blocking issues vs Suggestions. ## 1. Manifest (plugin.json) - File exists at .claude-plugin/plugin.json inside the plugin folder - name is present, lowercase, hyphenated, and matches the folder name - description is present and describes what the plugin does in one sentence - version follows semver (e.g. 1.0.0) ## 2. Marketplace registration - The plugin is listed in the root .claude-plugin/marketplace.json under plugins - Its source path correctly points to the plugin's folder - The name and description in marketplace.json match plugin.json exactly ## 3. Skills (SKILL.md) - Every skill has frontmatter with name and description - description clearly states when Coworker should use this skill, not just what it is - Instructions are concrete and step-by-step - No hardcoded secrets, credentials, or internal URLs ## Output format Report back as: Blocking issues (must fix before approval): - ... Suggestions (nice to have): - ... Overall: Approve / Needs changes
